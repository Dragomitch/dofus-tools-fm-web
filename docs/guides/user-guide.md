## Introduction

Dofus Tools est une plateforme complète proposant divers outils pour vous simplifier la vie sur **Dofus**.

Nos outils vous aident à :
- Optimiser votre builds de personnage
- Calculer vos ressources et gains
- Planifier vos aventures
- Gérer votre inventaire
- Et bien d'autres choses !

## Démarrage Rapide

### 1. Accéder à la Plateforme

1. Ouvrez votre navigateur web
2. Allez sur [https://dofus-tools.com](https://dofus-tools.com)
3. Vous arrivez sur la page d'accueil

### 2. Créer un Compte ou Se Connecter

- Si vous êtes nouveau : cliquez sur "S'inscrire"
- Si vous avez déjà un compte : cliquez sur "Se connecter"

### 3. Explorez les Outils

Une fois connecté, vous verrez tous les outils disponibles sur la page d'accueil.

## Créer un Compte

### Étape par Étape

1. **Cliquez sur "S'inscrire"** en haut à droite de la page

2. **Remplissez le formulaire** :
   - **Email** : Votre adresse email valide
   - **Nom d'utilisateur** : Votre pseudonyme (4-20 caractères)
   - **Mot de passe** : Au moins 8 caractères, avec majuscules et chiffres
   - **Confirmer le mot de passe** : Retapez votre mot de passe

3. **Acceptez les conditions** d'utilisation

4. **Cliquez sur "S'inscrire"**

5. **Vérifiez votre email** : Vous recevrez un email de confirmation. Cliquez sur le lien pour activer votre compte.

### Conseils de Sécurité

- Utilisez un mot de passe fort et unique
- N'utilisez pas le même mot de passe sur plusieurs sites
- Conservez votre adresse email à jour

## Se Connecter

### Première Connexion

1. Cliquez sur **"Se connecter"**
2. Entrez votre **email** et votre **mot de passe**
3. Cliquez sur **"Connexion"**

Vous serez redirigé vers votre tableau de bord personnel.

### Rester Connecté

Cochez l'option **"Me garder connecté"** pour ne pas vous reconnecter à chaque visite.

### Mot de Passe Oublié

1. Cliquez sur **"Mot de passe oublié ?"**
2. Entrez votre **adresse email**
3. Vous recevrez un email avec un lien de réinitialisation
4. Cliquez sur le lien et créez un nouveau mot de passe

## Outils Disponibles

### Catégories Principales

#### 1. Outils de Build
Optimisez votre équipement et vos caractéristiques :
- **Simulateur de Build** : Testez différentes combinaisons d'équipements
- **Optimiseur de Dégâts** : Maximisez vos dégâts
- **Calculateur de Résistance** : Calculez votre défense

#### 2. Outils de Combat
Préparez-vous pour le combat :
- **Calculateur de Dégâts** : Estimez vos dégâts contre les monstres
- **Générateur de Stratégies** : Obtenez des conseils tactiques
- **Analyseur de Sorts** : Comparez les sorts

#### 3. Outils de Métier
Gérez vos métiers :
- **Calculateur de Profit** : Estimez vos gains
- **Planificateur de Crafting** : Planifiez votre production
- **Gestionnaire de Ressources** : Suivez vos ressources

#### 4. Autres Outils
- **Calculateur d'Expérience** : Estimez le temps pour monter de niveau
- **Convertisseur de Ressources** : Convertissez entre différentes unités
- **Guide de Quêtes** : Trouvez des quêtes adaptées à votre niveau

## Sauvegarder vos Outils

### Ajouter aux Favoris

Vous pouvez sauvegarder vos outils préférés pour y accéder rapidement :

1. **Cliquez sur l'icône cœur** (♥) sur la carte d'un outil
2. L'outil est ajouté à vos **Favoris**
3. Accédez à vos favoris depuis le menu **"Mes Favoris"**

### Gérer vos Favoris

1. Allez dans **"Mes Favoris"**
2. Vous verrez tous vos outils favoris
3. Cliquez sur le cœur pour retirer un favori

### Accéder Rapidement à un Outil Favori

Une fois un outil marqué comme favori :
- Il s'affiche en haut de votre tableau de bord
- Vous pouvez le retrouver dans la section "Mes Favoris"

## Paramètres de Compte

### Modifier vos Informations Personnelles

1. **Cliquez sur votre nom** en haut à droite
2. Sélectionnez **"Paramètres de compte"**
3. Modifiez vos informations :
   - **Email** : Votre adresse email
   - **Nom d'utilisateur** : Votre pseudonyme
   - **Prénom/Nom** : Vos informations personnelles (optionnel)

4. Cliquez sur **"Enregistrer les modifications"**

### Modifier votre Mot de Passe

1. Allez dans **"Paramètres de compte"**
2. Cliquez sur **"Changer le mot de passe"**
3. Entrez votre **mot de passe actuel**
4. Entrez votre **nouveau mot de passe** (2 fois)
5. Cliquez sur **"Enregistrer"**

### Paramètres de Notification

1. Allez dans **"Paramètres de compte"**
2. Cliquez sur **"Notifications"**
3. Configurez vos préférences :
   - **Emails** : Recevoir les mises à jour par email
   - **Notifications navigateur** : Recevoir les notifications du navigateur
   - **Mises à jour** : Être informé des nouveaux outils

### Supprimer votre Compte

1. Allez dans **"Paramètres de compte"**
2. Cliquez sur **"Supprimer mon compte"**
3. **Confirmez** la suppression (irréversible)

**Attention** : La suppression de votre compte est permanente et toutes vos données seront effacées.

## Questions Fréquentes

### Q : Comment puis-je changer mon adresse email ?

**R** : Allez dans Paramètres de compte > Modifier les informations personnelles et changez votre email. Vous devrez confirmer le nouvel email.

### Q : Mon outil favori a disparu, comment le récupérer ?

**R** : Si vous avez supprimé un favori accidentellement, visitez simplement à nouveau l'outil et cliquez sur le cœur pour le rajouter à vos favoris.

### Q : Puis-je exporter mes données ?

**R** : Contactez notre support pour demander une export de vos données personnelles.

### Q : Combien de temps mes données sont conservées ?

**R** : Vos données sont conservées aussi longtemps que votre compte existe. Après suppression du compte, les données sont effacées dans les 30 jours.

### Q : Puis-je utiliser les outils sans compte ?

**R** : Certains outils de base sont disponibles sans compte, mais vous devez être connecté pour sauvegarder vos favoris et accéder aux fonctionnalités avancées.

### Q : Comment signaler un bug ?

**R** : Cliquez sur **"Signaler un problème"** en bas de la page et décrivez le bug rencontré.

### Q : Comment contribuer à l'amélioration des outils ?

**R** : Nous accueillons les suggestions ! Cliquez sur **"Envoyer une suggestion"** pour nous proposer une amélioration.
